# UTS-PROGRAM-WEB1
Proyek UTS Pemrograman Web 1 - Aplikasi Web Pemesanan Buku Online
Proyek ini merupakan implementasi aplikasi web sederhana berbasis front-end untuk sistem pemesanan buku online. Dibuat untuk memenuhi tugas Ujian Tengah Semester (UTS) mata kuliah Pemrograman Web 1.
📌 Indikator & Kriteria Penilaian
Struktur HTML: Menggunakan elemen HTML5 yang semantik, valid, dan terstruktur dengan rapi.
Pengelolaan Gaya (CSS): Desain responsif dan interaktif menggunakan CSS (Inline, Internal, dan External).
JavaScript & DOM:
Manipulasi DOM dinamis.
Validasi form (input email & password, checkout, pencarian pengiriman).
Manipulasi data tabel/katalog dari file data terpisah (data.js).
Interaksi UI berbasis dialog (modal box, pop-up, dan alert box).
Modularitas & Struktur File: Pemisahan berkas yang terorganisir sesuai spesifikasi tugas.
📁 Struktur Folder Proyek
tugas-uts-web1/
🚀 Fitur Utama
1. Halaman Login (index.html)
Form input Email dan Password.
Validasi Form: Menampilkan alert/pop-up error jika kombinasi email/password salah.
Modal Box / Pop-up:
Modal Lupa Password.
Modal Daftar Akun Baru.
2. Dashboard Menu (dashboard.html)
Fitur Greeting Dinamis: Menyapa pengguna berdasarkan waktu lokal perangkat (Pagi / Siang / Sore / Malam).
Navigasi cepat ke seluruh menu utama:
Informasi Stok / Katalog
Tracking Pengiriman
Laporan Pemesanan / Checkout
History Transaksi
3. Informasi Stok & Katalog (stok.html)
Menampilkan data katalog buku secara dinamis mengambil variable JSON dari js/data.js.
Fitur Tambah Stok Baru: Form interaktif untuk menambah baris katalog/stok buku secara langsung menggunakan JavaScript DOM.
4. Halaman Pemesanan (checkout.html)
Menampilkan rincian items/buku yang dipesan.
Fitur ubah/tambah kuantitas pemesanan secara langsung (real-time).
Form isian data informasi pemesan dan metode pembayaran.
5. Informasi Pengiriman (tracking.html)
Input nomor resi / Delivery Order.
Pencarian data pengiriman yang menampilkan: 
Nama Pemesan.
Status Pengiriman: Visualisasi progress bar / status indikator warna.
Detail ekpedisi, tanggal kirim, jenis paket, dan total pembayaran.
🛠️ Cara Menjalankan Proyek
Clone / Download repository atau folder proyek ini.
Buka folder proyek menggunakan code editor pilihan Anda (misal: VS Code).
Jalankan file index.html langsung melalui browser (bisa menggunakan Live Server di VS Code atau cukup klik ganda file index.html).
Isi Video: Penjelasan mengenai sistematika, alur berpikir, argumentasi struktur HTML, styling CSS, serta manipulasi JavaScript/DOM yang digunakan.
